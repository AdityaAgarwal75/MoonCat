# MoonCat identity — 1.0.7

Cream sleeping kitten inside a satin lilac crescent, fine champagne accents, warm ivory wordmark and midnight navy backgrounds. Applied to all launcher themes, TV banners, splash, profile background, in-app wordmarks and repository logo.

Five source assets were generated with the built-in imagegen tool: a transparent mark, transparent horizontal wordmark, 16:9 splash, 16:9 launcher banner and 16:9 profile background. Prompts specified the same kitten/crescent identity, quiet navy/lilac palette, legible MoonCat lettering, no tagline and safe negative space for TV controls. Assets were resized and compressed for Android; large backgrounds use drawable-nodpi to avoid density-driven decode inflation.
