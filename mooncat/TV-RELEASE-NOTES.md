MoonCat TV 1.0.4

- Studio logo rail, Home-style poster shelves, movie/series filters and incremental browsing across 11,655 metadata entries. Includes all eleven Wizarding films.
- Twenty Indian news channels with bundled logos and language filters. Fixed News24's old CDN and added a connection check with retry feedback.
- Fixed Hindi torrent sources being excluded when no direct URL exists. Audio switching checks embedded tracks, tries advertised dubbed alternatives, and verifies decoder tracks.
- Expanded CAM/TS/TC rejection, structured filename/language hints, Hindi/English fallback and seed-count ordering. Up to seven direct HTTP sample probes and four concurrent verified torrent preloads with deadlines and loser cleanup. A small startup sample is not a sustained bandwidth measurement.
- One Family profile. Previous profile data is retained on disk.
- Applied all five generated branding assets to their intended TV surfaces.
- Startup/resume update checks select TV APKs from GitHub releases; installation requires Android/Fire TV confirmation.
- MediaFusion added as an additional stream provider. Third-party availability is not guaranteed.

TV-focused release. The earlier mobile beta is not replaced by this build. Real Fire TV playback, hardware decoding, remote behaviour and home-network availability still require device testing.
